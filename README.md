# ALPS Device Console

Trustonic Senior Frontend Engineer take-home exercise: ALPS Device Console.

## Getting Started

```bash
npm install
npm run dev
```

The application runs locally against an MSW-mocked GraphQL service at `http://localhost:3000/graphql`.
